# Política de Privacidade - DJMasterDeck

**Última atualização:** 15/11/2026

## 1. Resumo
O DJMasterDeck é um aplicativo de áudio para DJ que funciona localmente no
dispositivo do usuário. **Não coletamos, armazenamos nem transmitimos dados
pessoais para servidores externos.**

## 2. Dados tratados localmente
- Arquivos de áudio selecionados pelo usuário (WAV, MP3, FLAC, OGG) são
  lidos apenas localmente para reprodução.
- Cenas (`.djmd`) e preferências (idioma, dispositivo de áudio, associações
  MIDI, atalhos) são salvas localmente no dispositivo.
- O microfone pode ser usado apenas se o usuário ativar o talkover; o áudio
  do microfone é processado localmente e não é gravado nem enviado.

## 3. Dados não coletados
- Não coletamos nome, e-mail, localização, identificadores de dispositivo
  ou dados de uso.
- Não usamos análise/telemetria de terceiros.
- Não compartilhamos dados com terceiros.

## 4. Permissões
- **Microfone**: usado somente para o recurso de talkover, mediante ação
  explícita do usuário.
- **Sistema de arquivos**: usado para abrir/salvar músicas e cenas escolhidas
  pelo usuário.
- **Internet**: usada apenas para abrir o manual em HTML no navegador padrão,
  quando solicitado.
